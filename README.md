---

## 📌 О проекте

HitechNoLifeEq — это открытый VST3-плагин, созданный для точечной работы со спектром на базе 8192-бинного FFT без лишней графической нагрузки на процессор. Управление происходит через командную строку (CMD) и интерактивные макросы.

### 🔥 Главные фишки:
* Zero-Latency Surgery: Точечное обнуление и сжатие частотных бинов без "мыла".
* CRT Console UI: Минималистичная ретро-графика, работающая с нулевой нагрузкой на GPU/CPU.
* Command Line Control: Поддержка команд (cut <freq>, 100hz +5dy -1db, /help).
* Micro-DAW Sandbox (Key-Key Architecture): Безопасная тестовая среда для прогона WAV-файлов и применения кастомных обработок без риска уронить основную DAW.

## 🛠 Установка (для пользователей)

1. Скачайте последнюю версию .vst3 из раздела Releases.
2. Поместите файл HitechNoLifeEq.vst3 в системную папку:
   C:\Program Files\Common Files\VST3\
3. Выполните сканирование плагинов в вашей DAW (FL Studio, Ableton, Cubase и т.д.).

## 🗺 Roadmap & Будущие архитектурные планы (Future Releases)

Проект трансформируется в модульную Layer-Based Micro-DAW систему:

### 🎯 1. Process Sandboxing & Fail-Safe Isolation (Изоляция Модулей)
* Принцип "Crash-Proof": Кастомные моды и внешние VST3-плагины (например, Serum) будут запускаться в изолированных контейнерах/потоках внутри подсистемы Micro-DAW.
* Авто-восстановление: Если сторонний VST/модуль выдает критическую ошибку (Access Violation), Micro-DAW мгновенно выгружает его из памяти без вылета основного плагина HitechNoLifeEq и без риска уронить проект в FL Studio/Ableton.
* В консоли выводится предупреждение: [ERROR] MODULE 'Serum_x64' ISOLATED AND UNLOADED SAFELY.

### 🎙 2. Direct WAV Recorder & Quick-Sampler
* Встроенная запись аудио напрямую с входа микрофона/канала в песочницу без лишних кликов в DAW.
* Автоматическая нарезка, закольцовка (Seamless Loop) и быстрый оффлайн-анализ спектра.

### 🥞 3. Layer-Based Architecture (Умное Наслоение)
* Отказ от громоздкой сетки из 100 дорожек микшера в пользу 2-уровневой системы слоев:
  * Main Layer: Drums, Kick, Snare, Main Lead.
  * Background Layer: Pads, Atmospheres, Bass.
* Интеллектуальная хирургия: Автоматический спектральный маскинг между слоями в реальном времени — плагин сам аккуратно вырезает конфликтные бины у бэкграунда, освобождая место для ведущих инструментов.
